# Flix

Flix is a lightweight interpreted programming language written in TypeScript.

Current Version

v0.01 Build 001

## Features

- Variables (`let`)
- Printing (`prt`)
- Integer numbers
- String literals
- Arithmetic (`+`, `-`, `*`, `/`)
- Operator precedence
- Comments
- Friendly syntax errors
- Friendly runtime errors

## Requirements

- Node.js
- npm

## Build

```bash
npm install
npm run build
```

## Run

```bash
npm start examples/hello.flx
```

## Example

```flix
let msg = "Hello, World!"
prt(msg)
```
